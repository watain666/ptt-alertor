04 / GOOD TO KNOW

你的問題，
這裡有答案。

開始使用前的幾個小問題。

更多使用說明 ↗
使用 Ptt Alertor 需要付費嗎？＋

不需要，Ptt Alertor 是開放原始碼的免費服務。這是由 TiâuÛi 維護的自架版本；如果喜歡這個專案，也歡迎到 GitHub 給我們一顆星。

需要提供我的 PTT 帳號密碼嗎？＋

不需要。只要在 Telegram 加入 @PttAlertorTiauiBot，即可設定公開看板的追蹤條件，不需要登入 PTT。

可以同時追蹤不同看板和關鍵字嗎？＋

可以！用半形逗號分隔，例如「新增 gossiping,movie 金城武,結衣」。也可以使用 &、! 或正規表示式設定更精準的比對條件，詳細用法請參考使用文件。

如何查看或取消我的訂閱？＋

傳送「清單」給機器人，即可查看訂閱。使用「刪除 看板 關鍵字」或「刪除作者 看板 作者」取消追蹤；將推噓文數設為 0 可停止該通知。傳送「指令」可查看所有操作。
